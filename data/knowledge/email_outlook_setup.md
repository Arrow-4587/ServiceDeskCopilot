# Outlook & Exchange Online Setup Guide

## Setting up Outlook Desktop
1. Launch Microsoft Outlook 365.
2. Enter your primary email address (`user@company.com`).
3. Click `Connect` and authenticate via Single Sign-On (SSO).

## OST File Repair
If Outlook fails to sync folders:
1. Close Outlook.
2. Navigate to `%LOCALAPPDATA%\Microsoft\Outlook`.
3. Rename the `.ost` file to `.old` and restart Outlook to rebuild local cache.

# Approved Software Request & Catalog Policy

## Self-Service Software Center
1. Open Windows Search and launch `Company Software Center`.
2. Browse approved applications (VS Code, Chrome, Slack, PowerBI).
3. Click `Install` (administrator privileges not required for catalog software).

## Unapproved Software Requests
- Installing unapproved software requires Security Team risk assessment and Manager approval.

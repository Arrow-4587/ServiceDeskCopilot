# Remote Work Security & BitLocker Guidelines

## Device Protection
- All corporate laptops must have BitLocker drive encryption enabled.
- Never leave corporate devices unattended in public spaces.

## BitLocker Recovery
If prompted for BitLocker recovery key:
1. Access `https://myaccount.microsoft.com/device-list` from a mobile phone.
2. Select your device and click `Get BitLocker Key`.

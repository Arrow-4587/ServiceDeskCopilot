# Corporate Wi-Fi Access Guide

## Network SSIDs
- `Company-Corp`: Secure WPA2-Enterprise network for managed corporate devices.
- `Company-Guest`: Isolated network for visitors.

## Connecting to Company-Corp
1. Select SSID `Company-Corp`.
2. EAP Method: PEAP (MSCHAPv2).
3. Identity: Enter `domain\username` or corporate email address.
4. Trust certificate issued by `Corp-CA-01`.
